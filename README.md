# TrayBridge Releases

This repository is the official public release and update distribution channel for TrayBridge.

## Downloads

Official TrayBridge releases are available from the **Releases** section of this repository.

The TrayBridge application source code is not published in this repository.

GitHub may automatically provide “Source code” archives for release tags. These archives contain only the files of this distribution repository and do not contain the TrayBridge application source code.

## Website

Official information and downloads are also available via the TrayBridge website.
